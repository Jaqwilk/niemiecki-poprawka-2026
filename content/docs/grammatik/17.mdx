Ta lekcja łączy trzy rzeczy:

1. <code>werden</code> — kim ktoś zostaje;
2. <code>wollen + bezokolicznik</code> — co ktoś chce zrobić;
3. <code>mit + Dativ</code> i <code>ohne + Akkusativ</code>.

<OneThing>
  <code>Er wird Arzt</code> znaczy „zostanie lekarzem”.
  <code>Er will Arzt werden</code> znaczy „chce zostać lekarzem”.
</OneThing>

## 1. <code>werden</code> — zostać

| osoba | forma |
| --- | --- |
| ich | <code>werde</code> |
| du | <code>wirst</code> |
| er / sie / es | <code>wird</code> |
| wir | <code>werden</code> |
| ihr | <code>werdet</code> |
| sie / Sie | <code>werden</code> |

<Rule title="Zawód bez rodzajnika">
  Po <code>werden</code> nazwa zawodu zwykle stoi bez
  <code>ein/eine</code>: <code>Ich werde Arzt</code>,
  <code>Sie wird Architektin</code>.
</Rule>

<Example
  german="Meine Schwester wird Ärztin. Mein Bruder wird Tierfotograf."
  polish="Moja siostra zostanie lekarką. Mój brat zostanie fotografem zwierząt."
/>

<Mistake
  wrong="Er werdet ein Arzt."
  correct="Er wird Arzt."
  explanation="Dla er używamy wird, a nazwa zawodu stoi tutaj bez rodzajnika."
/>

<Recall prompt="Was ___ ihr? (werden)" answer="werdet" />
<Recall prompt="Ona zostanie architektką." answer="Sie wird Architektin." />

## 2. <code>wollen</code> — chcieć

| osoba | forma |
| --- | --- |
| ich | <code>will</code> |
| du | <code>willst</code> |
| er / sie / es | <code>will</code> |
| wir | <code>wollen</code> |
| ihr | <code>wollt</code> |
| sie / Sie | <code>wollen</code> |

<Rule title="Klamra zdaniowa">
  Odmienione <code>wollen</code> stoi na pozycji 2. Czynność pozostaje w
  bezokoliczniku i zamyka zdanie.
</Rule>

| początek | pozycja 2 | środek | koniec |
| --- | --- | --- | --- |
| <code>Ich</code> | <code>will</code> | <code>im Ausland</code> | <code>leben.</code> |
| <code>Nach der Schule</code> | <code>will</code> | <code>ich Arzt</code> | <code>werden.</code> |
| <code>Nächstes Jahr</code> | <code>wollen</code> | <code>wir nach Spanien</code> | <code>fahren.</code> |

<Example
  german="Nach der Schule will ich Medizin studieren."
  polish="Po szkole chcę studiować medycynę. Element czasu jest pierwszy, will nadal zajmuje pozycję 2."
/>

<Mistake
  wrong="Ich will studiere Medizin."
  correct="Ich will Medizin studieren."
  explanation="Po czasowniku modalnym drugi czasownik ma formę bezokolicznika i stoi na końcu."
/>

<Mistake
  wrong="Nach der Schule ich will Arzt werden."
  correct="Nach der Schule will ich Arzt werden."
  explanation="Po elemencie czasu odmieniony czasownik nadal musi być na pozycji 2."
/>

## 3. <code>werden</code> czy <code>wollen … werden</code>?

| Sens | Zdanie |
| --- | --- |
| rezultat / przyszły zawód | <code>Er wird Arzt.</code> |
| własny zamiar | <code>Er will Arzt werden.</code> |

<Mistake
  wrong="Ich will Arzt."
  correct="Ich will Arzt werden."
  explanation="will potrzebuje czynności na końcu. Tutaj tą czynnością jest werden."
/>

## 4. <code>mit</code> i <code>ohne</code>

<Rule title="Kontrast do zapamiętania">
  <code>mit</code> zawsze wymaga Dativu. <code>ohne</code> zawsze wymaga
  Akkusativu.
</Rule>

| Rodzaj | <code>mit + Dativ</code> | <code>ohne + Akkusativ</code> |
| --- | --- | --- |
| męski | <code>mit meinem Freund</code> | <code>ohne meinen Freund</code> |
| nijaki | <code>mit meinem Handy</code> | <code>ohne mein Handy</code> |
| żeński | <code>mit meiner Freundin</code> | <code>ohne meine Freundin</code> |
| liczba mnoga | <code>mit meinen Eltern</code> | <code>ohne meine Eltern</code> |

<Example
  german="Ich fahre mit meinem Freund, aber ohne meine Eltern."
  polish="Jadę z przyjacielem, ale bez rodziców."
/>

<Example
  german="Ich arbeite mit meiner Kollegin und nie ohne mein Handy."
  polish="Pracuję z koleżanką i nigdy bez telefonu."
/>

<Mistake
  wrong="mit meinen Freund"
  correct="mit meinem Freund"
  explanation="mit → Dativ; mein Freund → meinem Freund."
/>

<Mistake
  wrong="ohne meinem Handy"
  correct="ohne mein Handy"
  explanation="ohne → Akkusativ; przy rodzaju nijakim zostaje mein Handy."
/>

## Sprawdź się
