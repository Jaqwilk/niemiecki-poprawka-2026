---
title: Lektion 17 — Ich will … werden
description: Zawody, plany, werden, wollen oraz mit + Dativ i ohne + Akkusativ.
icon: BriefcaseBusiness
---

W tej lekcji mówisz o zawodzie, nauce, pracy, podróżach i planach po szkole.
Musisz pilnować zarówno odmiany `werden/wollen`, jak i klamry zdaniowej:
odmieniony czasownik stoi na pozycji 2, a bezokolicznik na końcu.

<LessonMinimum>

- nazwać najważniejsze zawody i drogi kształcenia;
- powiedzieć, kim ktoś zostanie oraz kim chce zostać;
- opowiedzieć o planach na naukę, pracę, podróż i rodzinę;
- użyć wyrażeń pewności: `auf jeden Fall`, `vielleicht`, `hoffentlich`;
- odróżnić `mit + Dativ` od `ohne + Akkusativ`;
- poprawnie zamknąć zdanie bezokolicznikiem;
- napisać krótki blog o planach po zakończeniu szkoły.

</LessonMinimum>

<Example
  german="Er wird Arzt. Er will Arzt werden."
  polish="On zostanie lekarzem. On chce zostać lekarzem."
/>

<Rule title="Jedna główna reguła">
  `werden` mówi, kim ktoś zostaje. `wollen` mówi, czego ktoś chce. Po czasowniku
  modalnym odmienione `will` stoi na pozycji 2, a bezokolicznik zamyka zdanie:
  `Ich will Arzt werden.`
</Rule>

| Znaczenie | Wzór |
| --- | --- |
| przyszły zawód / rezultat | `Er wird Arzt.` |
| zamiar | `Er will Arzt werden.` |

<OneThing>
  `Ich will Arzt` jest niepełne. Po `will` potrzebujesz czynności na końcu:
  `Ich will Arzt werden`.
</OneThing>

<Recall
  prompt="Jak powiesz: Po szkole chcę zostać lekarzem?"
  answer="Nach der Schule will ich Arzt werden."
  hint="will na pozycji 2, werden na końcu; bez rodzajnika przed zawodem"
/>

## Słownictwo

### Zawody i nauka

| Niemiecki | Polski |
| --- | --- |
| der Polizist, die Polizisten | policjant |
| der Arzt, die Ärzte / die Ärztin, die Ärztinnen | lekarz / lekarka |
| der Tierarzt, die Tierärzte | weterynarz |
| der Tierfotograf, die Tierfotografen | fotograf zwierząt |
| der Lehrer, die Lehrer / die Lehrerin, die Lehrerinnen | nauczyciel / nauczycielka |
| der Architekt, die Architekten / die Architektin, die Architektinnen | architekt / architektka |
| der Schauspieler, die Schauspieler | aktor |
| der Politiker, die Politiker | polityk |
| der Krankenpfleger, die Krankenpfleger | pielęgniarz |
| der Traumberuf, die Traumberufe | wymarzony zawód |
| der Schulabschluss, die Schulabschlüsse | ukończenie szkoły |
| das Medizinstudium, die Medizinstudien | studia medyczne |
| der Studienplatz, die Studienplätze | miejsce na studiach |
| die Ausbildung, die Ausbildungen | kształcenie zawodowe |
| das Praktikum, die Praktika | praktyka / staż |

### Praca i kariera

- `studieren` — studiować;
- `im Büro / Krankenhaus arbeiten` — pracować w biurze / szpitalu;
- `Menschen helfen` — pomagać ludziom;
- `selbstständig sein` — pracować na własny rachunek;
- `eine Firma / ein Start-up gründen` — założyć firmę / start-up;
- `eine Firma besitzen` — posiadać firmę: `Meine Tante besitzt eine Firma.`;
- `Mir gehört eine Firma.` — Należy do mnie firma / Jestem właścicielem firmy;
- `eine Halbtagsstelle haben` — mieć pracę na pół etatu;
- `Geld verdienen` — zarabiać pieniądze;
- `super Noten haben` — mieć bardzo dobre oceny;
- `einen Job suchen` — szukać pracy.

### Plany i podróże

| Zwrot | Znaczenie |
| --- | --- |
| viele Pläne haben | mieć wiele planów |
| eine große Reise machen | odbyć dużą podróż |
| mit dem Rucksack durch Europa reisen | podróżować z plecakiem po Europie |
| im Ausland leben | mieszkać za granicą |
| Fremdsprachen lernen | uczyć się języków obcych |
| den Führerschein machen | zrobić prawo jazdy |
| mit dem Motorrad durch Europa fahren | jechać motocyklem po Europie |
| um die Welt segeln | żeglować dookoła świata |
| ein Instrument lernen | nauczyć się grać na instrumencie |
| auf einen Berg steigen | wejść na górę |
| heiraten / eine Familie haben | pobrać się / mieć rodzinę |

Przy krajach bez rodzajnika używasz `nach`: `nach Schweden fahren`, `nach
Italien reisen`, `nach Spanien reisen`. Kierunek geograficzny z rodzajnikiem
ma formę `in + Akkusativ`: `in den Süden fahren`.

### Jak pewny jest plan?

| Niemiecki | Sens |
| --- | --- |
| auf jeden Fall | na pewno |
| unbedingt | koniecznie |
| lieber | raczej / chętniej |
| vielleicht | być może |
| hoffentlich | mam nadzieję |
| auf keinen Fall | w żadnym razie |

<Example
  german="Vielleicht studiere ich Medizin. Auf jeden Fall will ich im Krankenhaus arbeiten."
  polish="Być może będę studiować medycynę. Na pewno chcę pracować w szpitalu."
/>

<Accordions>
  <Accordion title="Słowa międzynarodowe i rzeczy używane w ćwiczeniach">
    `international`, `die Influencerin`, `das Start-up`, `Crowdfunding`,
    `Lifestyle`, `Marketing`, `vegan`; ponadto `die Fitnessuhr` — zegarek
    fitness, `der E-Reader` — czytnik, `die E-Books`, `die Kreditkarte`,
    `die Kollegin`, `die Eltern`, `die Sonnenbrille`.
  </Accordion>
</Accordions>

## `werden` — zostać

| osoba | forma |
| --- | --- |
| ich | werde |
| du | wirst |
| er / sie / es | wird |
| wir | werden |
| ihr | werdet |
| sie / Sie | werden |

<Rule title="Zawód bez rodzajnika">
  Po `werden` nazwa zawodu zwykle stoi bez `ein/eine`:
  `Ich werde Arzt`, `Sie wird Architektin`.
</Rule>

<Example
  german="Du wirst auf jeden Fall Arzt. Dein Bruder wird vielleicht Tierfotograf."
  polish="Na pewno zostaniesz lekarzem. Twój brat być może zostanie fotografem zwierząt."
/>

<Mistake
  wrong="Er werdet ein Arzt."
  correct="Er wird Arzt."
  explanation="Dla `er` forma brzmi `wird`; przy podaniu zawodu nie potrzeba tu rodzajnika."
/>

<Recall prompt="Was ___ ihr? (werden)" answer="werdet" />
<Recall prompt="Moja siostra zostanie architektką." answer="Meine Schwester wird Architektin." />

## `wollen` — chcieć

| osoba | forma |
| --- | --- |
| ich | will |
| du | willst |
| er / sie / es | will |
| wir | wollen |
| ihr | wollt |
| sie / Sie | wollen |

<Rule title="Klamra zdaniowa">
  Odmienione `wollen` zajmuje pozycję 2. Czynność pozostaje w bezokoliczniku
  na końcu: `Ich will später im Ausland leben.`
</Rule>

| Początek | pozycja 2 | środek zdania | koniec klamry |
| --- | --- | --- | --- |
| `Nach der Schule` | `will` | `ich Arzt` | `werden.` |
| `Nächstes Jahr` | `wollen` | `wir nach Schweden` | `fahren.` |

<Example
  german="Zuerst will ich einen Job suchen und Geld verdienen."
  polish="Najpierw chcę szukać pracy i zarabiać pieniądze."
/>

<Example
  german="Nächstes Jahr wollen wir heiraten und eine Familie haben."
  polish="W przyszłym roku chcemy się pobrać i mieć rodzinę."
/>

<Mistake
  wrong="Ich will studiere Medizin."
  correct="Ich will Medizin studieren."
  explanation="Po czasowniku modalnym drugi czasownik ma formę bezokolicznika i stoi na końcu."
/>

### Szyk w pytaniu i po elemencie czasu

- `Was willst du nach dem Schulabschluss machen?`
- `Wollt ihr gern im Ausland leben?`
- `Nach dem Schulabschluss will ich eine Ausbildung machen.`
- `Auf keinen Fall werde ich Politiker.`

<Recall prompt="Ułóż: im Ausland / Luise / unbedingt / leben / will" answer="Luise will unbedingt im Ausland leben." />
<Recall prompt="Ułóż pytanie: ihr / werden / was / wollt" answer="Was wollt ihr werden?" />

## `werden` czy `wollen … werden`?

| Znaczenie | Zdanie |
| --- | --- |
| przewidywanie / przyszły zawód | `Er wird Arzt.` — Zostanie lekarzem. |
| własny zamiar | `Er will Arzt werden.` — Chce zostać lekarzem. |

<Mistake
  wrong="Ich will Arzt."
  correct="Ich will Arzt werden."
  explanation="`wollen` potrzebuje czynności na końcu. Gdy mówisz o zawodzie, tą czynnością jest `werden`."
/>

## `mit` + Dativ, `ohne` + Akkusativ

<Rule title="Najważniejszy kontrast">
  `mit` zawsze wymaga Dativu, a `ohne` — Akkusativu. Ten sam rzeczownik ma
  więc dwie formy: `mit meinem Freund`, ale `ohne meinen Freund`.
</Rule>

| Rodzaj | `mit` + Dativ | `ohne` + Akkusativ |
| --- | --- | --- |
| męski | mit dem / einem / meinem Freund | ohne den / einen / meinen Freund |
| nijaki | mit dem / einem / meinem Handy | ohne das / ein / mein Handy |
| żeński | mit der / einer / meiner Freundin | ohne die / eine / meine Freundin |
| liczba mnoga | mit den / meinen Büchern | ohne die / meine Bücher |

<Example
  german="Ich fahre mit dem Rad zur Arbeit, aber nie ohne mein Handy."
  polish="Jadę rowerem do pracy, ale nigdy bez telefonu."
/>

<Example
  german="Ich arbeite gern mit meiner Kollegin und reise ohne meine Eltern."
  polish="Chętnie pracuję z koleżanką i podróżuję bez rodziców."
/>

<Example
  german="Ohne einen Kaffee kann ich nicht arbeiten. Im Urlaub reise ich ohne Bücher, aber mit dem E-Reader und den E-Books."
  polish="Bez kawy nie mogę pracować. Na urlopie podróżuję bez książek, ale z czytnikiem i e-bookami."
/>

<Mistake
  wrong="mit meinen Freund"
  correct="mit meinem Freund"
  explanation="`mit → Dativ`; der Freund → dem Freund; mein → meinem."
/>

<Mistake
  wrong="ohne meinem Handy"
  correct="ohne mein Handy"
  explanation="`ohne → Akkusativ`; dla rodzaju nijakiego forma brzmi `mein Handy`."
/>

<Recall prompt="mit ___ Kollegin (mein)" answer="mit meiner Kollegin" />
<Recall prompt="ohne ___ Bücher (mein)" answer="ohne meine Bücher" />
<Recall prompt="Szukam domu z ogrodem." answer="Ich suche ein Haus mit einem Garten." />

### Plan, zamiar czy przyszły zawód?

<Exercise
  answer="1. przyszły zawód (`wird`); 2. zamiar (`will … werden`); 3. plan podróży (`will … fahren`)"
>
  Nazwij funkcję każdego zdania: 1. `Lena wird Ärztin.` 2. `Lena will Ärztin
  werden.` 3. `Nach dem Studium will sie nach Schweden fahren.` Następnie
  ułóż po jednym własnym zdaniu każdego typu.
</Exercise>

## Komunikacja

### Zawód i nauka

- `Was möchtest du nach dem Schulabschluss machen?`
- `Was willst du werden?`
- `Ich denke, ich werde vielleicht Tierarzt.`
- `Ich möchte etwas mit Tieren machen.`
- `Ich weiß es noch nicht.`
- `Das ist mein Traumberuf.`
- `Ist das Studium nicht schwierig?` — `Vielleicht. Aber ich finde es interessant.`

### Porządkowanie planu

- `Ach, ich habe viele Pläne.`
- `Zuerst will ich …`
- `Und dann?`
- `Danach möchte ich …`
- `Wohin wollt ihr fahren?`
- `Das ist eine gute Idee.`
- `Ich freue mich auf meine Freiheit.`

## Pisanie: blog o planach

Użyj kolejności:

1. kiedy zaczynają się plany;
2. co zrobisz najpierw;
3. jeden pewny plan z `auf jeden Fall`;
4. podróż albo nauka;
5. dalszy plan dotyczący pracy.

<Example
  german="Nach meinem Schulabschluss habe ich drei Monate frei. Zuerst will ich den Führerschein machen. Auf jeden Fall will ich mit dem Motorrad durch Europa fahren. Danach möchte ich arbeiten und Geld verdienen. Später will ich eine Firma gründen."
  polish="Model używa kolejności czasu i trzech różnych planów bez skomplikowanych zdań."
/>

<ExamTip>
  Po każdym zdaniu znajdź czasownik odmieniony i bezokolicznik. Jeśli używasz
  `wollen`, bezokolicznik powinien domknąć zdanie. Przy `mit/ohne` podkreśl
  przyimek i dopiero wtedy dobierz przypadek.
</ExamTip>

## Wymowa: akcent w słowach międzynarodowych

Posłuchaj i zaznacz najmocniejszą sylabę w słowach:
`international`, `studieren`, `Influencerin`, `Start-up`, `Crowdfunding`,
`Lifestyle`, `Marketing`, `vegan`.

Nie zakładaj automatycznie polskiego akcentu. Powtarzaj całe krótkie zdanie,
np. `Ich will Marketing studieren.`

## Co pojawia się w ćwiczeniach

- odmiana `werden` i dopasowanie zawodu;
- uzupełnienie dialogu o planach;
- budowanie zdań z `wollen` i bezokolicznikiem;
- wybór formy po `mit` albo `ohne`;
- układanie pytań i zdań z rozsypanki;
- rozpoznanie stopnia pewności planu;
- napisanie bloga o planach po szkole.

## Po tej lekcji potrafię…

- powiedzieć, kim ktoś zostanie i kim chce zostać;
- zbudować klamrę zdaniową z `wollen` i bezokolicznikiem;
- odróżnić `mit + Dativ` od `ohne + Akkusativ`;
- opowiedzieć o planie nauki, pracy i podróży.
