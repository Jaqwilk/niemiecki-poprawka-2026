# Treść edukacyjna

Notatki obejmują wyłącznie Momente A1.2, Lektion 13–18:

```text
content/docs/
├── index.mdx
└── lessons/
    ├── 13.mdx
    ├── 14.mdx
    ├── 15.mdx
    ├── 16.mdx
    ├── 17.mdx
    └── 18.mdx
```

Każda lekcja ma tę samą kolejność: aktywne przypomnienie, słownictwo sytuacyjne,
reguła z odpowiedzią „dlaczego”, przykłady, typowy błąd, komunikacja oraz krótki
sprawdzian. Dodatki nauczyciela są oznaczone osobno.

Komponenty `Rule`, `Example`, `Mistake`, `Recall`, `ExamTip`, `Exercise`,
`Flashcard` i `LessonComplete` są dostępne w MDX bez importów.
